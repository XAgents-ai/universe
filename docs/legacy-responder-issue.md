# Physically construct the full autonomous responder P–C–G–C–A

Hypothesis: from a declared seeded actuator plus loose raw components, charged `set`/`observe`/`claim` transitions can assemble a sensor-to-gate-to-mover chain whose physically implemented control responds after its builder disconnects.

Acceptance: a legal O2 witness with initial inventory, source and energy conditions, full action trace and replayable hashes; four counterfactuals (correct stimulus, wrong stimulus, cut signal path, disconnected/no-model); exact conservation every tick; multiple seeded live replays. No `env_ops`, hand-placed assembly or privileged controller code in the construction interval.

Do not substitute the already demonstrated smaller P–A responder for this goal. Bounded oracle failure is `NOT_ESTABLISHED`, not impossible.
